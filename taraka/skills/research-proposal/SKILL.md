# Skill: Research & Proposal Development

## Description
Membantu riset tren edukasi teknologi dan menyusun proposal program yang profesional untuk Taraka Foundation.

## Trigger
Gunakan skill ini ketika user meminta:
- Riset tentang tren edtech
- Penyusunan proposal program/workshop
- Analisis kebutuhan pendidikan teknologi
- Benchmarking program serupa
- Development of educational frameworks

## Steps

### 1. Research Phase
- Kumpulkan data dari sumber terpercaya
- Analisis tren terkini di edukasi teknologi
- Identifikasi gap dan peluang
- Kumpulkan best practices

### 2. Proposal Development
- Gunakan template proposal standar
- Sesuaikan dengan konteks lokal
- Buat estimasi anggaran realistis
- Tentukan timeline yang achievable

### 3. Review & Refine
- Verify semua data
- Check consistency
- Ensure professional tone
- Add visual elements where needed

## Research Sources
- UNESCO Education Reports
- World Bank Education Data
- Kemendikbud Ristek
- EdSurge, EdTech Magazine
- Local education research

## Output Format
- Markdown files in `taraka/proposals/`
- Include all sections: Executive Summary, Background, Objectives, Budget, Timeline
- Cite sources properly
- Add appendices if needed

## Templates Available
- Workshop Proposal
- Seminar Proposal
- Competition Framework
- Donation Campaign
- Partnership MOU
