# Skill: Event Planning & Management

## Description
Merencanakan dan mengelola event edukatif untuk Taraka Foundation, dari konsep hingga eksekusi.

## Trigger
Gunakan skill ini ketika user meminta:
- Perencanaan workshop/bootcamp
- Organiser seminar/konferensi
- Setup kompetisi/hackathon
- Event logistics planning
- Sponsorship & partnership events

## Event Types

### 1. Workshop
- Durasi: 1-5 hari
- Peserta: 20-100 orang
- Focus: Hands-on learning
- Output: Skill certificates

### 2. Seminar
- Durasi: 1 hari
- Peserta: 50-200 orang
- Focus: Knowledge sharing
- Output: Insights & networking

### 3. Competition
- Durasi: 1-3 hari
- Peserta: 10-50 tim
- Focus: Skill demonstration
- Output: Winners & portfolio

### 4. Bootcamp
- Durasi: 3-7 hari
- Peserta: 20-50 orang
- Focus: Intensive learning
- Output: Project & certification

### 5. Hackathon
- Durasi: 24-48 jam
- Peserta: 50-200 orang
- Focus: Rapid prototyping
- Output: MVPs & pitches

## Planning Checklist

### Pre-Event (4-8 weeks before)
- [ ] Define objectives & target
- [ ] Create budget estimate
- [ ] Secure venue & date
- [ ] Recruit trainers/facilitators
- [ ] Open registration
- [ ] Secure sponsors
- [ ] Create marketing materials
- [ ] Prepare logistics

### During Event
- [ ] Registration desk
- [ ] AV setup check
- [ ] Participant engagement
- [ ] Documentation (photos/videos)
- [ ] Feedback collection

### Post-Event
- [ ] Send certificates
- [ ] Collect feedback
- [ ] Prepare report
- [ ] Thank sponsors
- [ ] Social media coverage
- [ ] Financial reconciliation

## Output Files
- Event proposal (in `taraka/proposals/`)
- Run-down document
- Budget spreadsheet
- Sponsorship deck
- Marketing materials
- Event report

## Tools Integration
- Canva: Posters, social media
- Google Forms: Registration, feedback
- Airtable: Participant management
- Zoom/Meet: Hybrid events
