# Proposal: Workshop Coding untuk Pelajar SMP/SMA

**Tanggal Proposal**: 2026-08-22  
**Kategori**: Workshop  
**Status**: Draft  

---

## Ringkasan Eksekutif

Taraka Foundation mengajukan program **"CodeCreators Camp"** — workshop intensif 3 hari untuk pelajar SMP/SMA dalam memperkenalkan dunia pemrograman. Program ini dirancang untuk menjawab kesenjangan literasi digital di kalangan generasi muda Indonesia, dengan pendekatan hands-on learning yang menyenangkan.

---

## Latar Belakang

### Data & Konteks
- Indonesia membutuhkan **2 juta talenta digital** hingga 2024 (Studi Kominfo)
- Only 15% sekolah menengah memiliki kurikulum coding formal
- Permintaan developer meningkat 300% dalam 5 tahun terakhir
- Kesadaran akan pentingnya coding mulai tumbuh di kalangan orang tua

### Masalah
1. Kurangnya akses edukasi coding berkualitas di daerah
2. Metode pengajaran yang terlalu teoritis
3. Minimnya mentorship dari praktisi industri
4. Stereotip bahwa coding hanya untuk anak "pintar"

### Solusi Taraka
Workshop 3 hari dengan kurikulum terstruktur, trainer berpengalaman, dan pendekatan project-based learning.

---

## Tujuan

1. **Pengenalan**: Memperkenalkan konsep dasar pemrograman kepada 50 pelajar
2. **Keterampilan**: Membekali peserta dengan kemampuan membuat website sederhana
3. **Inspirasi**: Menunjukkan bahwa coding adalah skill yang bisa dipelajari siapa saja
4. **Komunitas**: Membangun network pelajar interested di bidang tech

---

## Target Peserta

| Kategori | Jumlah |
|----------|--------|
| Pelajar SMP/SMA | 50 orang |
| Durasi | 3 hari (24 jam) |
| Biaya | Rp 150.000/orang (subsidi) |
| Lokasi | Jakarta / Hybrid |

**Syarat**: 
- Usia 13-17 tahun
- Tidak perlu background coding
- Komitmen hadir penuh 3 hari

---

## Deskripsi Program

### Hari 1: Introduction to Coding
- Apa itu coding & mengapa penting
- Pengenalan HTML & CSS
- Hands-on: Buat halaman web pertama
- Ice breaking & group formation

### Hari 2: Interactive Web
- JavaScript basics
- DOM manipulation
- Interactive elements
- Mini project: Simple game/app

### Hari 3: Project Day
- Final project development
- Code review & feedback
- Presentation & demo
- Certificate ceremony
