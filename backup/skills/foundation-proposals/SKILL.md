# Foundation Proposal Writing

Create professional proposals for educational foundations and NGOs.

## Structure (11 Sections)
1. Ringkasan Eksekutif
2. Latar Belakang (with data)
3. Tujuan
4. Target Peserta
5. Deskripsi Program
6. Timeline
7. Anggaran
8. Expected Outcomes
9. Tim Pelaksana
10. Risiko & Mitigasi
11. Dokumen Pendukung

## Proposal Types
- Workshop/Training (1-5 days)
- Seminar/Conference (1 day)
- Competition/Hackathon (1-3 days)
- Grant Application
- Sponsorship Package

## Key Guidelines
- Formal Indonesian tone
- Data-driven arguments
- Include contingency budget (10%)
- Cite reputable sources
- Specify participant selection criteria

## Output Location
`foundation/proposals/<program-name>-YYYY-MM-DD.md`
