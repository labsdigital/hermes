# Tentang Buku Ini

Buku contoh ini dibuat untuk memperlihatkan seluruh komponen tata letak. Gantilah isinya dengan naskah Anda sendiri; strukturnya boleh dipertahankan.

:::stats
- 2 | Modul inti dengan pembuka halaman penuh
- 2 | Template siap salin
- 12+ | Komponen visual
:::

| Komponen | Keterangan |
|---|---|
| Sasaran | Guru, fasilitator, pengembang pelatihan |
| Format | PDF untuk dibagikan, DOCX untuk disunting |
| Edisi | 2026 |

:::catatan Semua contoh bersifat fiktif
Nama, angka, dan kasus di buku ini hanya ilustrasi untuk memperlihatkan tata letak.
:::

# Cara Membaca Buku Ini

Setiap modul mengikuti pola yang sama sehingga pembaca cepat menemukan bagian yang dibutuhkan.

{.steps}
1. **Baca pembuka modul** untuk melihat tujuan dan template yang tersedia.
2. **Pahami prinsipnya** melalui penjelasan singkat dan diagram.
3. **Praktikkan template** — salin, lalu ganti bagian dalam tanda [ ... ].
4. **Tutup dengan intisari** untuk mengingat poin terpenting.
