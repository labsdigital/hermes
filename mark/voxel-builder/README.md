# Voxel Builder - Editor untuk Anak-anak

Aplikasi web interaktif untuk membangun dunia voxel 3D!

## 🎮 Cara Menggunakan

1. **Pilih Warna** - Klik palet warna di kiri
2. **Tambah Blok** - Klik pada sisi blok untuk menambah
3. **Hapus Blok** - Pilih mode hapus, lalu klik blok
4. **Putar Dunia** - Drag untuk memutar, atau pakai tombol panah
5. **Simpan** - Simpan proyek ke browser

## ✨ Fitur

- 🎨 12 warna berbeda
- 🧊 Grid 5x5x5
- 🔄 Rotasi 360°
- 💾 Simpan & Muat proyek
- 📥 Ekspor ke JSON
- 🏠 Contoh rumah siap pakai
- 📱 Responsive design

## 🚀 Cara Menjalankan

Buka file `index.html` di browser, atau deploy ke GitHub Pages:

```bash
# Enable GitHub Pages
# Settings > Pages > Source: main branch
```
